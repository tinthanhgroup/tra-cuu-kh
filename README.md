# Tra cứu khách hàng – tư vấn GTGT tại quầy

Trang cho Cố vấn dịch vụ Hyundai Tín Thanh: nhập biển số để xem nhóm khách, hạng mục GTGT tới kỳ và lịch sử vào xưởng.

Repo này **chỉ chứa giao diện** (`index.html`). Dữ liệu khách nằm trên Google Drive, chỉ đọc qua Google Apps Script sau khi đăng nhập bằng mã CVDV và mật khẩu; không đưa dữ liệu khách vào repo.

Không sửa trực tiếp `index.html` ở đây: bản gốc nằm trong project, đẩy lên bằng `scripts/dang_github.py`.
